# Manual upload packs

Generated by `npm run social:draft` / `npm run social:export`.

Each subdirectory is one Instagram/Facebook-ready pack:

- `image.jpg` — Emily travel illustration (NVIDIA FLUX → Pollinations FLUX fallback); otherwise the place POI photo
- `source.jpg` — original POI photo kept when an illustration was generated
- `image-prompt.txt` — Emily scene prompt (always written; use for manual gen if API skipped)
- `caption.txt` — paste into the caption field
- `meta.json` — alt text, suggested KST post time, `is_ai_generated` / `image_ai_generated`
- `UPLOAD_NOTES.txt` — short checklist

Character reference: `scripts/social/assets/emily-reference.png`.  
No Meta API tokens required. See `docs/meta-setup.md`.
